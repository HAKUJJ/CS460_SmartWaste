# ♻️ Smart Waste Detective AI (Fusion Edition)
### โปรเจกต์จบรายวิชา CS460 - ระบบผู้ช่วยแยกขยะอัจฉริยะด้วยเทคนิค Feature Fusion

ระบบ AI ผู้ช่วยวิเคราะห์และแยกประเภทขยะเพื่อการทิ้งลงถังที่ถูกต้อง โดยใช้เทคนิค **Feature Fusion** ในการรวมพลังของสมองกล 2 ส่วนหลัก คือ โมเดลผู้เชี่ยวชาญด้านขยะ (12 คลาส) และโมเดลผู้เชี่ยวชาญด้านสิ่งมีชีวิต/สัตว์ (เพื่อป้องกันการทิ้งสิ่งมีชีวิตลงถังขยะ) จนได้โมเดลร่างสมบูรณ์ที่มีความแม่นยำรวมบนชุดข้อมูลทดสอบ (Validation Accuracy) สูงถึง **92.18%**

## 📂 โครงสร้างและไฟล์สำคัญในโปรเจกต์ (Project Structure)
- `app.py` : โค้ดหลักสำหรับรันระบบ Web Application Interface ด้วยไลบรารี Gradio
- `train_model.ipynb` : ไฟล์ Jupyter Notebook ที่ใช้สำหรับเทรนและประเมินผลโมเดลบน Kaggle (รวมถึงการสร้างกราฟ Confusion Matrix)
- `CS460_projectname.pdf` : สไลด์นำเสนอโปรเจกต์ (Presentation Slide) สำหรับการรายงานผล
- `binimage/` : โฟลเดอร์จัดเก็บไฟล์รูปภาพถังขยะสีต่างๆ (เขียว, เหลือง, แดง, น้ำเงิน) ที่แอปพลิเคชันจะเรียกแสดงผลตามประเภทขยะที่ AI ตรวจจับได้
- `requirements.txt` : ไฟล์ระบุรายชื่อไลบรารีและเวอร์ชันของ Python ที่จำเป็นต้องใช้ในการรันโปรเจกต์
